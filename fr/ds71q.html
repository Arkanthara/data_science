Exam questions

Explication complète du clustering et de l’algorithme k-means

Question

Expliquez le problème du regroupement et décrivez l’algorithme de regroupement k-means. En particulier, discutez de la fonction qu’il minimise et de sa relation avec un modèle gaussien.

Le problème fondamental du clustering

La recherche de structure dans le chaos

Imaginez que vous avez un sac de bonbons de formes et couleurs variées, mélangés aléatoirement. Votre cerveau fait naturellement ceci : il regroupe les bonbons similaires. Les ronds avec les ronds, les carrés avec les carrés, les rouges avec les rouges.

Le clustering (regroupement) est exactement cette capacité, mais pour des données. C’est une méthode non supervisée - personne ne vous dit comment regrouper, vous devez découvrir la structure par vous-même.

Définition mathématique formelle

Étant donné un ensemble de données \(\mathcal{X} = \{\mathbf{x}_1, \mathbf{x}_2, ..., \mathbf{x}_N\}\) avec \(\mathbf{x}_i \in \mathbb{R}^D\), le clustering cherche une partition de \(\mathcal{X}\) en \(K\) sous-ensembles \(C_1, C_2, ..., C_K\) tels que :

  1. Exhaustivité : \(\bigcup_{k=1}^K C_k = \mathcal{X}\)
  2. Exclusivité : \(C_i \cap C_j = \emptyset\) pour \(i \neq j\) (pour le clustering dur)
  3. Cohésion : Les points d’un même cluster se ressemblent
  4. Séparation : Les points de clusters différents sont dissimilaires

L’algorithme k-means : une idée géniale dans sa simplicité

L’analogie des représentants élus

Imaginez une région avec plusieurs villages. Pour réduire les temps de trajet, on veut construire \(K\) centres administratifs. Comment les placer optimalement ?

  1. Initialisation : Placez \(K\) centres au hasard
  2. Affectation : Chaque village choisit le centre le plus proche
  3. Réajustement : Chaque centre se déplace au barycentre des villages qui l’ont choisi
  4. Itération : Répétez jusqu’à stabilité

C’est l’essence de k-means !

Le cœur mathématique : la fonction objectif

Formalisation précise

Soient :

  • Données : \(\mathcal{X} = \{\mathbf{x}_i\}_{i=1}^N\), \(\mathbf{x}_i \in \mathbb{R}^D\)
  • Nombre de clusters : \(K\) (fixé a priori)
  • Centres des clusters : \(\mathbf{M} = \{\mu_k\}_{k=1}^K\), \(\mu_k \in \mathbb{R}^D\)
  • Variables d’affectation : \(\mathbf{Z} = \{z_{ik}\}\), où \(z_{ik} \in \{0, 1\}\) et \(\sum_{k=1}^K z_{ik} = 1\)

La fonction à minimiser

k-means minimise la somme des carrés des distances intra-cluster :

\[ J(\mathbf{M}, \mathbf{Z}) = \sum_{i=1}^{N} \sum_{k=1}^{K} z_{ik} \|\mathbf{x}_i - \mu_k\|_2^2 \]

Où \(\|\cdot\|_2\) est la norme euclidienne : \(\|\mathbf{x}\|_2 = \sqrt{\sum_{d=1}^D x_d^2}\)

Détail de la notation

Terme Signification Dimension
\(z_{ik}\) Variable binaire : 1 si \(\mathbf{x}_i\) ∈ cluster \(k\), 0 sinon Scalaire
\(\mathbf{x}_i\) Point de données \(i\) \(\mathbb{R}^D\)
\(\mu_k\) Centre du cluster \(k\) \(\mathbb{R}^D\)
\(\|\mathbf{x}_i - \mu_k\|_2^2\) Distance euclidienne au carré Scalaire

Observation cruciale : Pour un point \(\mathbf{x}_i\) donné, un seul \(z_{ik}\) vaut 1 (celui du cluster auquel il appartient), les autres valent 0. Donc pour chaque point, on ne compte que sa distance au centre de son propre cluster.

Optimisation par descente de coordonnées

Le problème combinatoire

Minimiser \(J\) simultanément sur \(\mathbf{M}\) et \(\mathbf{Z}\) est NP-dur : il y a \(K^N\) affectations possibles !

Stratégie : optimiser alternativement

On utilise une descente de coordonnées :

  1. Fixer \(\mathbf{M}\), optimiser sur \(\mathbf{Z}\) (étape E)
  2. Fixer \(\mathbf{Z}\), optimiser sur \(\mathbf{M}\) (étape M)
  3. Répéter jusqu’à convergence

Étape E : Optimisation des affectations

Avec \(\mathbf{M}\) fixé, le problème devient :

Pour chaque \(i = 1, ..., N\), choisir \(z_{ik}\) pour minimiser :

\[ \sum_{k=1}^K z_{ik} \|\mathbf{x}_i - \mu_k\|_2^2 \]

Sous contrainte : \(\sum_{k=1}^K z_{ik} = 1\), \(z_{ik} \in \{0, 1\}\)

Solution : Affecter \(\mathbf{x}_i\) au cluster dont le centre est le plus proche !

Formellement :

\[ z_{ik} = \begin{cases} 1 & \text{si } k = \arg\min_{j} \|\mathbf{x}_i - \mu_j\|_2^2 \\ 0 & \text{sinon} \end{cases} \]

Étape M : Optimisation des centres

Avec \(\mathbf{Z}\) fixé, le problème devient :

Pour chaque \(k = 1, ..., K\), trouver \(\mu_k\) minimisant :

\[ \sum_{i=1}^N z_{ik} \|\mathbf{x}_i - \mu_k\|_2^2 \]

Calcul du gradient

\[ \nabla_{\mu_k} \left( \sum_{i=1}^N z_{ik} \|\mathbf{x}_i - \mu_k\|_2^2 \right) = -2 \sum_{i=1}^N z_{ik} (\mathbf{x}_i - \mu_k) \]

Condition d’optimalité

En annulant le gradient :

\[ \sum_{i=1}^N z_{ik} (\mathbf{x}_i - \mu_k) = 0 \]

\[ \Rightarrow \mu_k = \frac{\sum_{i=1}^N z_{ik} \mathbf{x}_i}{\sum_{i=1}^N z_{ik}} \]

Interprétation : Le centre optimal est la moyenne (centre de masse) des points du cluster.

Preuve de convergence

Monotonie de la descente

Soit \(J^{(t)} = J(\mathbf{M}^{(t)}, \mathbf{Z}^{(t)})\)

  1. Étape E : On choisit \(\mathbf{Z}^{(t+1)}\) optimal pour \(\mathbf{M}^{(t)}\) fixé :

    \[ J(\mathbf{M}^{(t)}, \mathbf{Z}^{(t+1)}) \leq J(\mathbf{M}^{(t)}, \mathbf{Z}^{(t)}) \]

    (inégalité stricte si au moins une affectation change)

  2. Étape M : On choisit \(\mathbf{M}^{(t+1)}\) optimal pour \(\mathbf{Z}^{(t+1)}\) fixé :

    \[ J(\mathbf{M}^{(t+1)}, \mathbf{Z}^{(t+1)}) \leq J(\mathbf{M}^{(t)}, \mathbf{Z}^{(t+1)}) \]

    (inégalité stricte si au moins un centre change)

  3. Transitivité :

    \[ J^{(t+1)} = J(\mathbf{M}^{(t+1)}, \mathbf{Z}^{(t+1)}) \leq J(\mathbf{M}^{(t)}, \mathbf{Z}^{(t)}) = J^{(t)} \]

Conséquence

La séquence \(\{J^{(t)}\}_{t=0}^\infty\) est décroissante et minorée par 0, donc elle converge.

Attention : Elle converge vers un minimum local, pas nécessairement global !

Relation profonde avec les modèles gaussiens

De l’algorithme EM à k-means

Pour comprendre le lien, partons d’un modèle de mélange de gaussiennes (GMM).

Modèle de mélange de gaussiennes

On suppose que les données sont générées par \(K\) gaussiennes :

\[ p(\mathbf{x}) = \sum_{k=1}^K \pi_k \mathcal{N}(\mathbf{x} | \mu_k, \Sigma_k) \]

Où :

  • \(\pi_k\) est le poids du cluster \(k\) (\(\pi_k \geq 0\), \(\sum_k \pi_k = 1\))
  • \(\mathcal{N}(\mathbf{x} | \mu_k, \Sigma_k)\) est une gaussienne multivariée

Variables latentes

Introduisons des variables latentes \(\mathbf{z}_i = [z_{i1}, ..., z_{iK}]\) avec \(z_{ik} \in \{0, 1\}\) et \(\sum_k z_{ik} = 1\), indiquant à quel cluster appartient \(\mathbf{x}_i\).

Modèle complet

La distribution jointe s’écrit :

\[ p(\mathbf{x}_i, \mathbf{z}_i) = \prod_{k=1}^K [\pi_k \mathcal{N}(\mathbf{x}_i | \mu_k, \Sigma_k)]^{z_{ik}} \]

L’algorithme EM pour GMM

EM maximise la log-vraisemblance des données observées par rapport aux paramètres \(\theta = \{\pi_k, \mu_k, \Sigma_k\}\).

Étape E (Expectation)

On calcule la responsabilité (postérieure) :

\[ \gamma(z_{ik}) = \frac{\pi_k \mathcal{N}(\mathbf{x}_i | \mu_k, \Sigma_k)}{\sum_{j=1}^K \pi_j \mathcal{N}(\mathbf{x}_i | \mu_j, \Sigma_j)} \]

C’est une affectation douce : \(\gamma(z_{ik}) \in [0, 1]\), \(\sum_k \gamma(z_{ik}) = 1\).

Étape M (Maximization)

On maximise l’espérance de la log-vraisemblance complète :

\[ Q(\theta, \theta^{\text{old}}) = \sum_{i=1}^N \sum_{k=1}^K \gamma(z_{ik}) \left[ \log \pi_k + \log \mathcal{N}(\mathbf{x}_i | \mu_k, \Sigma_k) \right] \]

Les mises à jour sont :

\[ \mu_k^{\text{new}} = \frac{\sum_{i=1}^N \gamma(z_{ik}) \mathbf{x}_i}{\sum_{i=1}^N \gamma(z_{ik})} \]

\[ \Sigma_k^{\text{new}} = \frac{\sum_{i=1}^N \gamma(z_{ik}) (\mathbf{x}_i - \mu_k^{\text{new}})(\mathbf{x}_i - \mu_k^{\text{new}})^\top}{\sum_{i=1}^N \gamma(z_{ik})} \]

\[ \pi_k^{\text{new}} = \frac{\sum_{i=1}^N \gamma(z_{ik})}{N} \]

Passage à k-means : hypothèses simplificatrices

Hypothèse 1 : Covariances sphériques et égales

Supposons \(\Sigma_k = \sigma^2 I\) pour tout \(k\), avec \(\sigma^2\) fixé et identique pour tous les clusters.

La densité gaussienne devient :

\[ \mathcal{N}(\mathbf{x}_i | \mu_k, \sigma^2 I) = \frac{1}{(2\pi\sigma^2)^{D/2}} \exp\left(-\frac{\|\mathbf{x}_i - \mu_k\|^2}{2\sigma^2}\right) \]

Hypothèse 2 : Limite de variance nulle

Considérons la limite quand \(\sigma^2 \to 0\) (distributions très “pointues”).

Dans ce cas, \(\exp\left(-\frac{\|\mathbf{x}_i - \mu_k\|^2}{2\sigma^2}\right)\) décroît très rapidement avec la distance.

Hypothèse 3 : Poids égaux

Supposons \(\pi_k = 1/K\) pour tout \(k\) (clusters équiprobables a priori).

Dérivation de la fonction objectif k-means

Étape E en limite dure

Quand \(\sigma^2 \to 0\), la responsabilité \(\gamma(z_{ik})\) devient :

\[ \gamma(z_{ik}) \to \begin{cases} 1 & \text{si } k = \arg\min_j \|\mathbf{x}_i - \mu_j\|^2 \\ 0 & \text{sinon} \end{cases} \]

C’est exactement une affectation dure comme dans k-means !

Étape M simplifiée

Avec ces hypothèses, l’espérance \(Q\) devient (à une constante additive près) :

\[ Q(\theta, \theta^{\text{old}}) \approx -\frac{1}{2\sigma^2} \sum_{i=1}^N \sum_{k=1}^K \gamma(z_{ik}) \|\mathbf{x}_i - \mu_k\|^2 + \text{constante} \]

Maximiser \(Q\) équivaut alors à minimiser :

\[ \sum_{i=1}^N \sum_{k=1}^K \gamma(z_{ik}) \|\mathbf{x}_i - \mu_k\|^2 \]

Avec l’affectation dure \(\gamma(z_{ik}) = z_{ik}\), on retrouve exactement la fonction \(J\) de k-means !

Tableau récapitulatif : EM → k-means

Aspect EM pour GMM général k-means (cas limite)
Affectation Douce (probabiliste) Dure (déterministe)
Covariances \(\Sigma_k\) quelconques \(\Sigma_k = \sigma^2 I\)
Variance Apprise des données \(\sigma^2 \to 0\)
Poids \(\pi_k\) appris \(\pi_k = 1/K\)
Fonction objectif Log-vraisemblance Somme des distances au carré

Implications pratiques de cette connexion

Ce que cela nous apprend sur k-means

  1. Hypothèse de sphéricité : k-means suppose des clusters sphériques (même variance dans toutes les directions)

  2. Sensibilité aux échelles : Comme les gaussiennes ont même covariance, k-means est sensible à la normalisation des données

  3. Hypothèse d’égalité de variance : Tous les clusters sont supposés avoir la même “dispersion”

  4. Limite de faible recouvrement : k-means fonctionne mieux quand les clusters sont bien séparés

Conséquences pour l’application

  • Normalisation nécessaire : Toujours normaliser les données avant d’appliquer k-means
  • Forme des clusters : k-means détecte mal les clusters allongés ou de formes complexes
  • Choix de K : Plus difficile quand les clusters ont des variances très différentes

Version intuitive finale

L’essence en une image

Message à retenir

k-means est un cas particulier d’EM où l’on suppose que chaque cluster est une gaussienne sphérique de même variance, et où l’on prend la limite où ces gaussiennes sont infiniment “pointues” (faible variance).

Cette compréhension théorique explique :

  • Pourquoi k-means fonctionne si bien sur certains problèmes
  • Quand l’utiliser (clusters compacts et sphériques)
  • Comment l’améliorer (bonne initialisation, normalisation)

Le génie de k-means est d’avoir simplifié au maximum un problème complexe pour obtenir un algorithme rapide, simple et efficace dans de nombreux cas pratiques.

Pour les plus curieux : approfondissements

Généralisations possibles

  1. k-medoids : Utilise un point réel comme centre (moins sensible aux outliers)
  2. Fuzzy C-means : Affectation probabiliste comme EM
  3. k-means avec métriques différentes : Distance de Manhattan, cosinus…

Défis ouverts

  • Choix automatique de K : Méthode du coude, critères d’information…
  • Clusters de densités variables : DBSCAN comme alternative
  • Grandes dimensions : Malédiction de la dimensionnalité

La beauté de k-means réside dans son équilibre entre simplicité mathématique, efficacité computationnelle et interprétabilité intuitive - une combinaison rare et puissante en science des données.
