Entropie Conditionnelle

Question

Expliquez l’entropie conjointe et conditionnelle pour des variables aléatoires discrètes.

Expliquez la règle de chaîne pour l’entropie.

Introduction : Rappel sur l’entropie

L’entropie d’une variable aléatoire discrète \(X\), notée \(H(X)\), mesure l’incertitude moyenne associée à ses réalisations. Elle se définit par :

\[ H(X) = -\sum_{x \in \mathcal{X}} p(x) \log_2 p(x) \]

Nous allons maintenant étendre ce concept à plusieurs variables.

Entropie conjointe

L’entropie conjointe mesure l’incertitude totale liée à la réalisation simultanée de plusieurs variables aléatoires.

Définition mathématique

Pour deux variables aléatoires discrètes \(X\) et \(Y\) ayant une distribution conjointe \(p(x,y)\), l’entropie conjointe \(H(X,Y)\) est définie comme :

\[ H(X,Y) = -\sum_{x \in \mathcal{X}} \sum_{y \in \mathcal{Y}} p(x,y) \log_2 p(x,y) \]

Pour \(N\) variables \(X_1, X_2, \dots, X_N\) avec distribution conjointe \(p(x_1, x_2, \dots, x_N)\) :

\[ H(X_1, X_2, \dots, X_N) = -\sum_{x_1} \sum_{x_2} \dots \sum_{x_N} p(x_1, x_2, \dots, x_N) \log_2 p(x_1, x_2, \dots, x_N) \]

Interprétation

  • \(H(X,Y)\) représente le nombre moyen de bits nécessaires pour encoder la paire \((X,Y)\) de manière optimale.
  • C’est l’incertitude associée à la connaissance simultanée des deux variables.
  • Si \(X\) et \(Y\) sont indépendantes, on a \(H(X,Y) = H(X) + H(Y)\) (voir plus bas).

Exemple simple

Considérons deux variables binaires \(X\) et \(Y\) avec la distribution conjointe suivante :

\(X\)  \(Y\) 0 1
0 0.25 0.25
1 0.25 0.25

Ici, \(p(x,y) = 0.25\) pour toutes les paires. Calculons \(H(X,Y)\) :

\[ H(X,Y) = -4 \times (0.25 \log_2 0.25) = -4 \times (0.25 \times (-2)) = 2 \text{ bits} \]

Chaque paire nécessite en moyenne 2 bits pour être encodée.

Entropie conditionnelle

L’entropie conditionnelle mesure l’incertitude restante sur une variable aléatoire lorsqu’on connaît la valeur d’une autre variable.

Définition mathématique

L’entropie conditionnelle de \(Y\) sachant \(X\) est notée \(H(Y|X)\) et définie par :

\[ H(Y|X) = \sum_{x \in \mathcal{X}} p(x) H(Y|X=x) \]

Où \(H(Y|X=x)\) est l’entropie de la distribution conditionnelle \(p(y|x)\) :

\[ H(Y|X=x) = -\sum_{y \in \mathcal{Y}} p(y|x) \log_2 p(y|x) \]

En combinant les deux expressions, on obtient la forme plus courante :

\[ H(Y|X) = -\sum_{x \in \mathcal{X}} \sum_{y \in \mathcal{Y}} p(x,y) \log_2 p(y|x) \]

Interprétation

  • \(H(Y|X)\) est l’incertitude moyenne sur \(Y\) qui subsiste après avoir observé \(X\).
  • C’est une espérance : on moyenne l’incertitude sur \(Y\) pour chaque valeur possible de \(X\), pondérée par la probabilité de \(X\).
  • Propriété importante : \(H(Y|X) \leq H(Y)\) avec égalité si et seulement si \(X\) et \(Y\) sont indépendantes.

Exemple simple

Reprenons les variables binaires précédentes mais avec une distribution dépendante :

\(X\)  \(Y\) 0 1
0 0.5 0
1 0 0.5

Ici, \(Y\) est parfaitement déterminé par \(X\) : si \(X=0\) alors \(Y=0\), si \(X=1\) alors \(Y=1\).

Calculons \(H(Y|X)\) : - Pour \(X=0\) : \(p(y|0) = [1, 0]\), donc \(H(Y|X=0) = 0\) - Pour \(X=1\) : \(p(y|1) = [0, 1]\), donc \(H(Y|X=1) = 0\)

Ainsi, \(H(Y|X) = p(X=0) \times 0 + p(X=1) \times 0 = 0\) bit.

La connaissance de \(X\) élimine toute incertitude sur \(Y\).

Règle de chaîne pour l’entropie

La règle de chaîne (chain rule) pour l’entropie établit une relation fondamentale entre l’entropie conjointe et les entropies conditionnelles.

Énoncé

Pour deux variables aléatoires \(X\) et \(Y\) :

\[ H(X,Y) = H(X) + H(Y|X) \]

Plus généralement, pour \(N\) variables \(X_1, X_2, \dots, X_N\) :

\[ H(X_1, X_2, \dots, X_N) = H(X_1) + H(X_2|X_1) + H(X_3|X_1,X_2) + \dots + H(X_N|X_1,X_2,\dots,X_{N-1}) \]

Ou sous forme compacte :

\[ H(X_1, X_2, \dots, X_N) = \sum_{i=1}^N H(X_i|X_1, \dots, X_{i-1}) \]

avec la convention que \(H(X_1|\emptyset) = H(X_1)\).

Démonstration intuitive

Pour deux variables, partons de la définition de l’entropie conjointe :

\[ H(X,Y) = -\sum_{x,y} p(x,y) \log_2 p(x,y) \]

Utilisons la factorisation \(p(x,y) = p(x) \cdot p(y|x)\) :

\[ \begin{aligned} H(X,Y) &= -\sum_{x,y} p(x,y) \log_2 [p(x) \cdot p(y|x)] \\ &= -\sum_{x,y} p(x,y) [\log_2 p(x) + \log_2 p(y|x)] \\ &= -\sum_{x,y} p(x,y) \log_2 p(x) - \sum_{x,y} p(x,y) \log_2 p(y|x) \end{aligned} \]

Le premier terme : \[ -\sum_{x,y} p(x,y) \log_2 p(x) = -\sum_x \left[ \log_2 p(x) \sum_y p(x,y) \right] = -\sum_x p(x) \log_2 p(x) = H(X) \]

Le second terme est exactement \(H(Y|X)\) par définition.

Ainsi, \(H(X,Y) = H(X) + H(Y|X)\).

Interprétation

La règle de chaîne se comprend intuitivement :

  • L’incertitude totale sur la paire \((X,Y)\) [= \(H(X,Y)\)] est égale à l’incertitude sur \(X\) [= \(H(X)\)] plus l’incertitude restante sur \(Y\) après avoir connu \(X\) [= \(H(Y|X)\)].
  • On peut étendre à \(N\) variables : l’incertitude totale se décompose en incertitude sur la première variable, plus l’incertitude sur la seconde sachant la première, etc.

Conséquences importantes

  1. Indépendance : Si \(X\) et \(Y\) sont indépendantes, alors \(p(y|x) = p(y)\), donc \(H(Y|X) = H(Y)\), et la règle devient \(H(X,Y) = H(X) + H(Y)\).

  2. Inégalité de sous-additivité : Comme \(H(Y|X) \leq H(Y)\), on a toujours \(H(X,Y) \leq H(X) + H(Y)\).

  3. Ordre des variables : La règle est symétrique : \(H(X,Y) = H(Y) + H(X|Y)\).

Exemple d’application

Considérons un système de transmission où \(X\) est le message envoyé et \(Y\) le message reçu (potentiellement bruité).

  • \(H(X)\) : incertitude sur le message émis
  • \(H(Y|X)\) : incertitude introduite par le bruit (équivaut à l’entropie du bruit)
  • \(H(X,Y)\) : incertitude totale sur la paire émission-réception

La règle de chaîne nous dit que l’incertitude totale est la somme de l’incertitude sur l’émission et de l’incertitude due au bruit.

Exemple complet illustratif

Prenons deux variables binaires \(X\) et \(Y\) avec distribution conjointe :

\(X\)  \(Y\) 0 1 \(p(x)\)
0 0.3 0.2 0.5
1 0.1 0.4 0.5
\(p(y)\) 0.4 0.6 1.0

  1. Calcul de \(H(X)\) : \[ H(X) = -[0.5 \log_2 0.5 + 0.5 \log_2 0.5] = 1 \text{ bit} \]

  2. Calcul de \(H(Y)\) : \[ H(Y) = -[0.4 \log_2 0.4 + 0.6 \log_2 0.6] \approx 0.971 \text{ bits} \]

  3. Calcul de \(H(X,Y)\) : \[ H(X,Y) = -[0.3 \log_2 0.3 + 0.2 \log_2 0.2 + 0.1 \log_2 0.1 + 0.4 \log_2 0.4] \approx 1.846 \text{ bits} \]

  4. Calcul de \(H(Y|X)\) :

    • Pour \(X=0\) : \(p(Y|0) = [0.3/0.5 = 0.6, 0.2/0.5 = 0.4]\), \(H(Y|X=0) = -[0.6 \log_2 0.6 + 0.4 \log_2 0.4] \approx 0.971\)
    • Pour \(X=1\) : \(p(Y|1) = [0.1/0.5 = 0.2, 0.4/0.5 = 0.8]\), \(H(Y|X=1) = -[0.2 \log_2 0.2 + 0.8 \log_2 0.8] \approx 0.722\)
    • \(H(Y|X) = 0.5 \times 0.971 + 0.5 \times 0.722 \approx 0.8465\) bits

  5. Vérification de la règle de chaîne : \[ H(X,Y) = H(X) + H(Y|X) \approx 1 + 0.8465 = 1.8465 \text{ bits} \] Ce qui correspond bien à notre calcul direct (aux arrondis près).

Résumé et synthèse

Concept Définition Interprétation Relation
Entropie conjointe \(H(X,Y)\) \(-\sum_{x,y} p(x,y) \log_2 p(x,y)\) Incertitude totale sur le couple \((X,Y)\) -
Entropie conditionnelle \(H(Y|X)\) \(-\sum_{x,y} p(x,y) \log_2 p(y|x)\) Incertitude restante sur \(Y\) après observation de \(X\) \(H(Y|X) \leq H(Y)\)
Règle de chaîne \(H(X,Y) = H(X) + H(Y|X)\) Décomposition de l’incertitude totale Généralisable à N variables

Points clés à retenir

  1. L’entropie conjointe mesure l’incertitude combinée de plusieurs variables.
  2. L’entropie conditionnelle quantifie l’information encore cachée dans une variable quand une autre est connue.
  3. La règle de chaîne est un outil puissant pour décomposer l’entropie conjointe en somme d’entropies conditionnelles.
  4. Ces concepts sont fondamentaux en théorie de l’information, avec des applications en compression, transmission de données, apprentissage automatique (gain d’information, arbres de décision) et bien d’autres domaines.

La compréhension de ces notions permet d’analyser les dépendances entre variables et d’optimiser les systèmes de traitement de l’information.
