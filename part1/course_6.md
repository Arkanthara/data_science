# What is a Gaussian Mixture model (GMM)?

We have $X$. We want to compute the density function over $\Omega$.
In fact, we will assume that this probability density function follows a set of function given by GMM.

The density $f(x)$ is generated by $c$ "basis" functions $\phi$ (components), from a family $\mathbb{F}$

$$f(x) = \sum_j^c \pi_j \phi(x, \theta_j)$$

- $\pi_j \in \mathbb{R}$ are the mixture parameters
- $\phi(x, \theta_j) \in \mathbb{F}$ are functions controlled by parameters $\theta_j$

### Assumptions

1. Number of components ($c \in \mathbb{N}^*$) is known
2. family of functions $\mathbb{F}$ is known
3. Labels (class/components labels) are unknown
(4. each sample is independant !!!)

- Density $f(x)$ represents a random process where $x$ is drawn from a set of states $\omega_j$ with prior probability $P(\omega_j)$


$$f(x) = \sum_j^c \pi_j \phi(x, \theta_j)$$
$$f(x) = P(x | \theta) = \sum_j^c P(\omega_j)P(x|\omega_j, \theta_j)$$
We get:
- $\pi_j = P(\omega_j)$
- $\phi(x, \theta_j) = P(x | \omega_j, \theta_j)$

### Likelihood

$$P(X|\theta) = \prod_i^NP(x_i | \theta)$$

Because each sample is independant identicaly distributed !!!

Likelihood estimate $\hat{\theta} = argmax_{\theta}P(X|\theta)$

### Log-likelihood

$$L(\theta, X) = \sum_i^N \log(P(x_i|\theta)) =\sum_i^N \log \left[ \sum_j^c \pi_j \phi(x_i, \theta_j)\right]$$
Here the $+$ don't allow to maximize the log-likelihood for $c > 1$ !!! => EM algorithm approximate it !!!

Density function: positive, integral equal to 1 !!

## Definition

$\phi$ is a probability density function $\longrightarrow$ choosing the (agnostic) normal density family as basis ($\phi \in \mathbb{F} = {\mathbf{N}/\mu, \Sigma}$) seems reasonable:

$$f(x) = \sum_j^c \pi_j \mathbf{N}(x | \mu_j, \Sigma_j) \Longrightarrow \phi_j(x) = \phi(x|\theta_j) = \mathbf{N}(\mu_j, \Sigma_j)$$

- Can approximate any density
- enables a linear system of its parameters when maximizing the log-likelihood (MLE)

# How to interpret the E-step?

Compute responsibilites for every data and every component

Introduce $\delta_i \in \mathbb{R}^c, \delta_{ij} = (x_i \in c_j)$

We can only estimate $\delta_i$

We can infer the (statistical) contribution of $\gamma_{ij}$ for every data $x_i$ (responsability of each component is given by:)

$$\gamma_{ij}(\theta^0) = P(\delta_{ij} = true | \theta^0, X)$$
$$\gamma_{ij}(\theta^0) = \frac{\pi_1\phi(x_i, \theta^0_1)}{\pi_1^0\phi(x_i, \theta^0_1) + \pi_2^0\phi(x_i, \theta^0_2)}$$

We estimate how many data have been generated by each component !!!!

Soft labels/class/cluster/component assignment: $\sum_j \gamma_{ij} = 1 \ \ \forall i$

Virtually we split data into small parts 

# How to interpret the M-step?

Estimation of mixture parameters

$\frac{\gamma_{i1}}{\sum_k^N \gamma_{k1}}$: proportion of sample generated by component $1$ divided by sample generated by other components

Given the responsability of every data $\gamma_{ij}$, we can estimate the parameters of every component by (weighted) maximum likelihood.

$$\hat{\mu_1} = \frac{\gamma_{i1}}{\sum_k^N \gamma_{k1}}x_i$$
$$\hat{\Sigma_1} = \frac{\gamma_{i1}}{\sum_k^N \gamma_{k1}}(x_i - \hat{\mu_1})^T(x_i - \hat{\mu_1})$$
# Discuss the relationship betwen GMM and k-means

k-means is a hard assignment !!! (not good separation if there is less data in a gaussian compared to another...)

In GMM, it's a soft assignment !!! (with $\delta_{ij}$ a hot vector for assignments) (good separation of data becase take care about importance of each gaussian !!!)
